# Guide de contribution

Merci de votre intérêt pour contribuer au script epitest-docker ! Voici quelques lignes directrices simples pour contribuer au projet.

## Comment contribuer

1. Forkez le projet
2. Créez une branche pour votre fonctionnalité (`git checkout -b feature/ma-fonctionnalite`)
3. Committez vos changements (`git commit -m 'Ajout de ma fonctionnalité'`)
4. Poussez vers la branche (`git push origin feature/ma-fonctionnalite`)
5. Ouvrez une Pull Request

## Bonnes pratiques

- Testez vos modifications sur au moins un des systèmes supportés
- Gardez le code simple et lisible
- Mettez à jour la documentation (README.md) si nécessaire
- Expliquez clairement vos modifications dans les messages de commit

## Signaler un bug

Si vous trouvez un bug, ouvrez une issue en incluant :
- Le système d'exploitation utilisé
- Les étapes pour reproduire le bug
- Le comportement attendu vs le comportement observé

## Questions

Pour toute question, n'hésitez pas à ouvrir une issue avec le tag "question".
